# Serbian — basic words

A practical list of words and meanings for generating `data/cards.json`.

One row = one distinct meaning = one future card.

`Priority` (1–10) = when this meaning enters learning: 1 core ~100, 2 next ~200, 3 next ~500, 4–5 A1 rest, 6–7 A2, 8 B1, 9 B2, 10 C1+. Empty for `skip` rows.
