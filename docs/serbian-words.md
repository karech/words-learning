# Сербский язык — базовые слова

Практический словарь для повседневной жизни в Сербии. Источник для `data/cards.json` (см. `docs/vocabulary-cards-generation-spec.md`).

Формат: одна строка = одно значение = одна карточка.

| Srpski | Как читать | Значение | ID |
|---|---|---|---|

Колонка `ID`:

- пусто — ещё не импортировано;
- `sr_00123` — импортировано, это `id` карточки в `data/cards.json`;
- `skip: <причина>` — рассмотрено, карточка не нужна (форма слова, дубль по смыслу и т.п.).

Правила:

- одно слово с несколькими значениями → несколько строк, по одной на значение;
- новое значение → новая строка с пустым `ID` под словом;
- одно и то же слово+значение встречается в списке один раз (повторы удалены, остаётся первое вхождение);
- `ID` никогда не меняется и не переиспользуется.
